# 方法局限与反思草稿（多识模型，`baijuyi_poems` ×《白氏六帖》傅藏本）

首先需要明确的是，本轮结果直接建立在新版 `baijuyi_poems` 与傅藏本《白氏六帖》的完整比对之上，因此所有阈值、候选结构和图示解释都必须从这一组材料的内部统计出发重新建立。换言之，本轮矩阵不是若干局部样本的拼接，而是针对当前文本边界整体生成的结果。

在方法层面，类书侧也不再采用“部类 + 词条 + 注文”的简单拼接文本，而是按 `词条 / 注文 / 部类及部类附名` 三通道分别编码，再做加权合成。这样做能更明确地区分头词支点、解释性注文与知识门类三种不同来源的相似度贡献，但同时也意味着：权重设定本身会影响结果排序，仍需在后续细读中反复校验。

其次，“多识”模型在这一轮直接比对中的分值结构，仍然显示出诗级相对保守、句级更活跃的特征。诗级最佳匹配均值为 ` 0.6293 `，最大值为 ` 0.7642 `；句级最佳匹配均值为 ` 0.6408 `，最大值为 ` 1.0000 `。这说明模型在整首诗编码时会把局部成句与典故支点稀释到更大的语境之中，而在更细粒度层面则更容易把显性成句、制度词组与注文片段拉到前列。

第三，向量相似度衡量的始终只是语义邻近、表达结构接近与知识颗粒重合，而不是文献来源关系本身。即使像《效陶潛體詩十六首其四》之“酩酊”这样看似显性的样本，也只能说明诗句与类书条目之间存在高度贴近关系，而不能自动推出白居易必然直接取材于该条目。对于《想東遊五十韻》或《井底引銀瓶》这类依赖注文说明层建立联系的样本，更需要回到具体语境与文献传播环境中进一步辨析。

第四，当前候选分布明显偏向可归类、可命名、可概述的知识性门类。高频部类主要包括 老（150）、食（134）、酒（109）、貧（93）、俸禄（70）。这一现象当然可能反映白居易诗歌与类书知识结构之间的真实联系，但也可能部分体现模型自身对于显性词条、制度概念和固定搭配的偏好。因此，本轮结果最稳妥的定位仍然是一套偏向“显性支点发现”和“知识型互文筛选”的辅助机制，而不是最终定论的自动生产器。

因而，对古典文学研究而言，最稳妥的路径仍应是：先以“多识”完成大规模初筛，再回到文本细读、文献考证和更早典源辨析之中，完成最终论证。
