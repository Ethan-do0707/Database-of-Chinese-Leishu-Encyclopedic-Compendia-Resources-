# 白居易诗歌与《白氏六帖》互文密度计算数学报告

## 1. 数据对象与符号

当前 v5 结果目录为 `output_duoshi_fuzang_baijuyi_v5_note_type_35340`，类书侧采用 `note_type_aware_channels` 口径。类书记录数为 `35,340`，白居易诗作数为 `2,804`，白居易句级单位数为 `32,941`。句级矩阵形状为 `35,340 × 32,941`，诗级矩阵形状为 `35,340 × 2,804`，向量维度为 `1024`，矩阵 dtype 为 `float16`。

设类书条目集合为 `A = {a_i}`，白居易诗歌句级单位集合为 `L = {l_j}`，白居易整首诗集合为 `P = {p_k}`。多识模型将文本编码为向量后，以余弦相似度衡量类书条目与诗歌单位的接近程度：

`s(i,j) = cos(v(a_i), v(l_j)) = v(a_i) · v(l_j) / (||v(a_i)|| ||v(l_j)||)`

其中类书向量 `v(a_i)` 不是简单拼接文本，而是依据 `注文類型` 进行分流：补足下文整体编码，对仗偏重注文，解释文意和出处原文采用词条、注文、部类/部类附名三通道加权，出处典籍另做书名统计与普通语义 fallback。该策略由 `run_summary.json` 中的 `leishu_embedding_strategy` 记录。

## 2. 高值阈值与关系集合

句级展示阈值记为 `τ_L = 0.7134`，诗级展示阈值记为 `τ_P = 0.6689`。两者来自 `duoshi_fuzang_analysis_stats.json` 与论文展示版工作簿。句级高值关系集合定义为：

`E_L = {(a_i, l_j) | s(i,j) >= τ_L, 且该关系进入论文展示版 Top-K 高值表}`

诗级高值关系集合定义为：

`E_P = {(a_i, p_k) | s(i,k) >= τ_P, 且该关系进入论文展示版高值表}`

由当前文件统计，`|E_L| = 6,154`，`|E_P| = 451`。这些数字对应论文展示版 Top-K 高值关系，因同一句诗可以对应多个《六帖》条目，所以它们衡量的是“关系条数”，不是“被覆盖的诗句数”。

## 3. 口径一：论文展示版 Top-K 高值关系密度

Top-K 高值关系密度以高值关系条数为分子，用于衡量类书条目与诗歌单位之间形成了多少条可展示的高相似连接。句级公式为：

`D_relation_line = |E_L| / |L| × 1000`

代入当前数据：`6,154 / 32,941 × 1000 = 186.8189` 条/千句。

诗级关系密度公式为：

`D_relation_poem = |E_P| / |P| × 100`

代入当前数据：`451 / 2,804 × 100 = 16.0842` 条/百首。

该口径的优点是保留“一句诗同时连接多个类书条目”的网络强度，适合讨论知识门类与诗句之间的多重连接；局限是同一句诗被多次计入，容易放大重复命中的影响。

## 4. 口径二：p90 高值句数 ÷ 全部句数

为衡量诗歌文本内部有多少句子实际进入高相似区间，需要把高值关系集合投影到诗句集合。定义句级命中集合：

`U_L = {l_j | 存在 a_i，使得 (a_i, l_j) ∈ E_L}`

p90 高值句数密度定义为：

`D_sentence = |U_L| / |L|`

代入当前数据：`3,302 / 32,941 = 0.100240 = 10.02%`，折合 `100.2398` 个高值句/千句。

相应地，诗级覆盖率可写作：

`D_poem_coverage = |U_P| / |P|`，其中 `U_P = {p_k | 存在 a_i，使得 (a_i, p_k) ∈ E_P}`。

代入当前数据：`282 / 2,804 = 10.06%`。

该口径的优点是去除了同一句诗多次命中造成的重复计数，更适合说明互文关系在白居易诗歌句级单位中的覆盖面；局限是它压缩了同一句诗内部的多重类书连接信息。

## 5. 两种口径的数学关系

两种口径之间满足：

`|E_L| >= |U_L|`

当同一句诗命中多个类书条目时，`|E_L|` 会大于 `|U_L|`。可以定义重复命中系数：

`M_line = |E_L| / |U_L|`

当前句级重复命中系数为 `6,154 / 3,302 = 1.8637`。这表示每个进入 p90 高值区间的诗句，平均对应约 `1.86` 条《六帖》高值关系。诗级重复命中系数为 `451 / 282 = 1.5993`。

| 指标 | 公式 | 数值 | 解释 |
| --- | --- | --- | --- |
| 句级 Top-K 高值关系密度 | `card(E_L) / card(L) × 1000` | 186.82 条/千句 | 保留同一句多条类书连接 |
| 句级 p90 高值句数密度 | `card(U_L) / card(L) × 100` | 10.02% | 同一句只计一次，表示覆盖面 |
| 诗级高值关系密度 | `card(E_P) / card(P) × 100` | 16.08 条/百首 | 整诗层面的关系条数 |
| 诗级覆盖率 | `card(U_P) / card(P) × 100` | 10.06% | 至少命中一次的诗作比例 |

## 6. 分组密度公式

若按诗类、作年、创作阶段或单诗分组，设某一分组为 `G`，该组全部句级单位为 `L_G`。该组高值关系集合为：

`E_G = {(a_i, l_j) ∈ E_L | l_j ∈ L_G}`

该组去重高值句集合为：

`U_G = {l_j ∈ L_G | 存在 a_i，使得 (a_i, l_j) ∈ E_G}`

则关系密度和句数密度分别为：

`D_relation(G) = |E_G| / |L_G| × 1000`

## 8. 解释边界

- Top-K 高值关系密度适合说明类书条目与诗句之间的连接规模，但不能直接等同于被影响的诗句比例。
- p90 高值句数密度适合说明诗句覆盖面，但会折叠同一句诗内部的多重类书连接。
- 两种口径均以当前 v5 展示阈值为前提，不能与旧数据规模或旧阈值直接混算。
- 高相似关系是互文候选，不等同于自动判定直接取材；涉及共同典源、公式化语句和礼制套语时，仍需结合 `排除共同典源后的排他性统计.json` 与代表样本人工复核。

## 9. 可写入论文的方法表述

可表述为：在 `32,941` 个白居易诗歌句级单位中，论文展示版 Top-K 高值关系共 `6,154` 条，关系密度为 `186.82` 条/千句；若将同一句诗的多个《六帖》命中去重，则 p90 高值句为 `3,302` 个，占全部句级单位的 `10.02%`。前者反映类书条目与诗句之间的连接强度，后者反映高相似互文在诗歌文本中的覆盖面；二者合用，可以避免单纯关系数放大重复命中的问题，也避免单纯覆盖率抹去多重知识连接。
