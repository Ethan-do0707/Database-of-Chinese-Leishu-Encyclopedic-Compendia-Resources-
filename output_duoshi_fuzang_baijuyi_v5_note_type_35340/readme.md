# 多识模型《白氏六帖》傅藏本 × 白居易诗歌互文计算结果（v5 注文类型口径）

本目录保存《白氏六帖事类集》（傅藏本）与白居易诗歌之间的“多识”向量互文计算结果。数据来自本地输出目录 `output_duoshi_fuzang_baijuyi_v5_note_type_35340`，采用 `note_type_aware_channels` 口径。

## 数据规模

- 类书记录：`35,340` 条
- 白居易规范化诗作：`2,804` 首
- 白居易句级单位：`32,941` 个
- 诗级矩阵：`35,340 × 2,804`
- 句级矩阵：`35,340 × 32,941`
- 向量维度：`1024`
- 矩阵 dtype：`float16`

## 方法说明

类书侧采用注文类型感知的多通道策略：

- `补足下文`：词条与解析注文合并为整体语义文本后编码。
- `对仗`：以解析注文作为主要语义通道。
- `解释文意`、`出处原文`：词条、注文、部类/部类附名三通道加权。
- `出处典籍`：抽取书名，与诗歌注释引书和共同典源作独立统计。
- `互见`：先解析 `見上注`、`並見上注`、`見某門/具某門` 等注文互见，再进入加权计算。

## 展示阈值与高相似样本

- 诗级展示阈值：`>= 0.6689`
- 句级展示阈值：`>= 0.7134`
- 诗级高相似关系：`451` 条，覆盖 `282` 首诗
- 句级高相似关系：`6,154` 条，覆盖 `3,302` 个句级单位
- 候选互文：`100` 组

## 互文密度口径

本目录同时保留两种互文密度口径，二者不可混用，但应合并解释：

| 口径 | 公式 | 当前数值 | 解释 |
| --- | --- | --- | --- |
| 论文展示版 Top-K 高值关系密度 | `句级高值关系数 / 全部句数 × 1000` | 186.82 条/千句 | 同一句命中多个《六帖》条目时重复计数，表示连接规模 |
| p90 高值句数密度 | `去重 p90 高值句数 / 全部句数 × 100` | 10.02% | 同一句只计一次，表示句级覆盖面 |
| 诗级关系密度 | `诗级高值关系数 / 全部诗作 × 100` | 16.08 条/百首 | 整诗层面的高值关系规模 |
| 诗级覆盖率 | `至少命中一次的诗作数 / 全部诗作 × 100` | 10.06% | 整诗层面的覆盖面 |

句级关系数为 `6,154`，去重高值句数为 `3,302`，说明每个进入 p90 高值区间的诗句平均对应约 `1.86` 条《六帖》高值关系。详细定义、公式和分组密度请见 `白氏六帖_白居易_互文密度数学报告.md`。

## 大文件说明

GitHub 普通仓库不适合直接存放大型二进制文件；超过 100MiB 的文件会被阻止，超过 50MiB 的文件也会触发警告。因此，本目录中超过 50MiB 的矩阵、向量和大型 Excel 文件均按 Git LFS 处理。其中句级完整矩阵 `similarity_matrix_白氏六帖_x_白居易_line_float16.npy` 超过 2GiB，发布时拆分为 `large_file_parts/` 下的分片文件。

如需在本地恢复句级完整矩阵，可在下载所有分片后按顺序合并：

```python
from pathlib import Path

target = Path("similarity_matrix_白氏六帖_x_白居易_line_float16.npy")
parts = sorted(Path("large_file_parts").glob("similarity_matrix_白氏六帖_x_白居易_line_float16.npy.part*"))
with target.open("wb") as out:
    for part in parts:
        with part.open("rb") as src:
            for chunk in iter(lambda: src.read(8 * 1024 * 1024), b""):
                out.write(chunk)
```

## 引用建议

若在论文或数据说明中引用本结果，建议注明：本数据采用本地“多识”向量模型，对《白氏六帖事类集》（傅藏本）`35,340` 条类书记录与白居易 `2,804` 首诗、`32,941` 个句级单位进行余弦相似度计算，并在类书侧采用注文类型感知的多通道加权策略。密度统计同时报告 Top-K 高值关系密度与 p90 高值句数密度，以区分连接规模和句级覆盖面。

## 注意事项

- 本结果用于数字人文研究中的互文候选发现，不等同于自动判定直接取材关系。
- 涉及《初学记》《艺文类聚》共同典源的情况，应结合 `排除共同典源后的排他性统计.json` 与代表样本继续人工复核。
- SikuBERT 相关材料仅作为历史/模型参照，不应与本目录 v5 注文类型口径作绝对同口径比较。
