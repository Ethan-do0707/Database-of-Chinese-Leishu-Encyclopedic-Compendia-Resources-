# 《唐類函》结构化说明

本项目从识典古籍章节页内嵌的 `window._ROUTER_DATA` 读取目录、章节与行级正文数据。

## 字段

- `volume`：目录中的卷名，如 `卷一`。
- `category`：脚本从正文短标题中识别的部类，如 `天部一`。
- `topics`：部类下的门目，如 `天一`、`日二`。
- `layers`：门目内按 `敘事`、`事對`、`詩文` 聚合的层次。
- `items`：条目。`lineType=1` 作为正文或条目名，`lineType=2` 作为注文，`lineType=3` 作为分页标记。
- `raw_lines`：源页面行级数据，保留 `line_id`、`line_type`、页码标记和原始文本，用于复核解析结果。

## 解析原则

- 未出现明确层次标记前，默认归入 `敘事`。
- 遇到 `事對` 时切换到 `事對`，若 `事對` 与第一个条目粘连在同一行，会拆出条目文本。
- 出现 `詩曰`、`賦曰`、`頌曰`、`贊曰`、`銘曰` 等文体标记的条目归入 `詩文`，置信度标为启发式。
- 所有推断都不覆盖原始行；若解析与原文冲突，以 `raw_lines` 为准。
