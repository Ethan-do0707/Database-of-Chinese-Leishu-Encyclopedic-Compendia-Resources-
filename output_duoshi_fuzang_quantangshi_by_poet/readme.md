# 多识模型《白氏六帖》傅藏本 × 《全唐诗》诗人互文候选统计

本目录保存《白氏六帖事类集》（傅藏本）与《全唐诗》之间的诗人层互文候选统计结果。数据采用“类书文本 3-gram 候选召回 + 多识向量精排”的口径。

- 多识 embedding 模型：`C:\duoshi_web\duoshi\models\fine_tuned\bge-large-zh-v1.5`。
- 类书向量：`D:\中大中文系工作相关\論文發表與投稿\大语言模型的白氏六帖\output_duoshi_fuzang_quantangshi_by_poet\vec_白氏六帖.npy`。类书侧分通道向量经数值等价性审计后复用既有缓存，并按当前行索引重新合成；审计文件为 `D:\中大中文系工作相关\論文發表與投稿\大语言模型的白氏六帖\output_duoshi_fuzang_quantangshi_by_poet\duoshi_web_quantangshi_encoder_equivalence.json`。

## 方法说明

本目录没有构造《全唐诗》全部句级单位与《白氏六帖》全部类书记录之间的穷举语义矩阵，而是先用类书 `词条 / 解析注文 / 注文` 的 3-gram 片段召回候选诗句，再对候选句使用多识 embedding 与类书侧向量做流式 best1 精排。

类书侧沿用 `note_type_aware_channels` 口径：先处理无实义词条与互见注文，再按注文类型分流；`补足下文` 使用词条与解析注文合并向量，`对仗` 突出注文通道，`解释文意 / 出处原文 / 出处典籍 / 互见` 等采用词条、注文、部类三通道加权或相应回退策略。

## 阈值口径

- 阈值采用候选集内部经验分位，不是人工定谳。
- 句级 `p90 = 0.741651`；句级 `p95 = 0.772558`。
- 诗级由句级 best1 汇总，`p90 = 0.751183`；`p95 = 0.783411`。

## 注意事项

- 本结果用于互文候选发现，不等同于自动判定直接取材关系。
- 高比率小样本诗人需要加最低诗数或最低句数门槛后再解释。
- 若论文需要“全量语义互文”表述，应另行运行全量句级语义检索或 ANN 近似检索。
- 《全唐诗》SQL 源数据中的作者名尾随数字已用于归一化分组；原作者名仍保存在索引表中。
