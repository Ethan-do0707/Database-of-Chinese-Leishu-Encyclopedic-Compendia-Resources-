# 《文选》结构化

本目录收录《文选》正文与李善注文的结构化工作簿，以及基于注文内容的五维初步研究编码结果。

## 文件说明

- `wenxuan_structured_20260721/文选_正文注文结构化.xlsx`：基础结构化数据。主表为 `正文注文`，含卷数、文类名、部类名、作品名、正文、注文六列；共 19,399 条正文—注文记录，覆盖卷一至卷六十。
- `wenxuan_annotation_20260722/文选_正文注文_五维标注.xlsx`：在基础数据上新增五个研究编码字段：`注释类型`、`释事完整度`、`释意操作`、`终止位置`、`意旨指向`。非空注文为 19,256 条；无注文的 143 条记录在五个编码字段中保持空白。

## 五维编码选项

| 维度 | 选项 |
| --- | --- |
| 注释类型 | 出处考证 / 字词训诂 / 语义阐发 / 混合型 |
| 释事完整度 | 有 / 无 / 部分 |
| 释意操作 | 有 / 无 |
| 终止位置 | 止于“事” / 延伸至“意” |
| 意旨指向 | 局部 / 整体 / 无 |

五维标注用于初步研究编码。涉及边界个案、统计结论或论文引证时，建议回看注文原文并进行分层人工复核。
