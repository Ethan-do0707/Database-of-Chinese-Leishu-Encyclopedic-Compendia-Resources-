## 3. 文本单位定义

### 3.1 类书侧单位

类书侧单位为《白氏六帖事类集》（傅藏本）结构化 JSON 中的一条记录。每条记录经 `note_type_aware_channels` 注文类型感知策略得到一个向量。设第 i 条类书记录为 r_i，其向量为 x_i。

类书侧向量不是简单拼接文本，而是沿用项目既定的分流策略：

- `补足下文`：词条与解析注文合并成连续语义文本后编码。
- `对仗`：以注文为主要语义通道。
- `解释文意`、`出处原文`：词条、注文、部类/部类附名三通道加权。
- `出处典籍`：书名线索单列统计，同时可进入带书名统计的加权策略。
- `互见`：先解析 `見上注`、`並見上注`、`見某門/具某門` 等互见注文，再参与编码。

### 3.2 诗歌侧单位

诗歌侧有两层单位：

- 诗级单位：一首诗，索引表为 `column_index_全唐诗_poem.csv`。
- 句级单位：按诗句或句段切分的单位，索引表为 `column_index_全唐诗_line.csv`。

全量诗级单位为 41,734 首，全量句级单位为 437,491 条。由于采用候选召回，真正进入多识精排的句级单位为 11,275 条。

## 4. 候选召回口径

设类书文本片段集合为 T，T 由类书记录的 `词条`、`解析注文`、`注文` 抽取。对 T 中文本取长度为 3 的连续字符片段，形成 3-gram 集合 G。对《全唐诗》全量句级单位 u，若 u 的文本包含任一 g ∈ G，则 u 被纳入候选集合 C。

形式化写作：

```text
G = { 所有来自类书词条、解析注文、注文的 3-gram }
C = { u ∈ U | exists g ∈ G, g 是 u 的子串 }
candidate_rate = |C| / |U|
```

实际取值：

- 类书 3-gram 数：`396,689`
- 全量句级单位 |U|：`437,491`
- 候选句级单位 |C|：`11,275`
- 候选召回比例：`0.025772`，即 `2.5772%`
- 全量句级比较对数：`15,460,931,940`
- 候选句级比较对数：`398,458,500`
- 相对全量对数压缩比例：`97.4228%`

这一设计使结果偏向显性词语、固定辞式、礼制公式与共同典源线索。未进入 C 的诗句不参与多识精排，因此本目录不是全量语义检索。

## 5. 向量相似度与 best1 定义

对候选句 u 与类书记录 r_i，设其向量分别为 y_u 与 x_i，采用余弦相似度：

```text
s(u, r_i) = cos(y_u, x_i) = (y_u · x_i) / (||y_u|| ||x_i||)
```

对每一个候选句 u，只保留相似度最高的一条类书记录，称为 best1：

```text
r*(u) = argmax_{r_i ∈ R} s(u, r_i)
b(u) = max_{r_i ∈ R} s(u, r_i)
```

`全唐诗_line_best1.csv` 中的 `row_id` 即 r*(u)，`best_similarity` 即 b(u)。

诗级结果不是整诗全文向量的重新编码，而是由句级 best1 回填汇总：某诗 m 若含候选句，则其诗级 best1 分数取该诗候选句 best1 的最大值。

```text
B(m) = max_{u ∈ C_m} b(u)
```

其中 C_m 表示诗 m 中进入候选集合 C 的句级单位。没有候选句的诗不出现在 `全唐诗_poem_from_line_best1.csv` 中，但在诗人密度分母中仍计入诗作总数。

## 6. 阈值定义

| 层级 | 统计量 | 阈值 | 定义 |
| --- | --- | --- | --- |
| 句级 | p90 | 0.7417 | 候选句 best1 相似度的第 90 百分位 |
| 句级 | p95 | 0.7726 | 候选句 best1 相似度的第 95 百分位 |
| 诗级 | p90 | 0.7512 | 候选诗 best1 相似度的第 90 百分位 |
| 诗级 | p95 | 0.7834 | 候选诗 best1 相似度的第 95 百分位 |
| 句级 | 0.8 | 0.8000 | 人工设定的强相似参考线 |
| 诗级 | 0.8 | 0.8000 | 人工设定的强相似参考线 |

p90 与 p95 均为候选 best1 分布内部的经验分位阈值。设候选句 best1 分数集合为 S_l = {b(u) | u ∈ C}，则：

```text
τ_l90 = quantile(S_l, 0.90)
τ_l95 = quantile(S_l, 0.95)
```

诗级阈值同理，基于候选诗 best1 分数集合 S_p = {B(m)}：

```text
τ_p90 = quantile(S_p, 0.90)
τ_p95 = quantile(S_p, 0.95)
```

0.8 不是分位数，而是额外设定的强相似参考线，用于观察更严格的高值样本。

## 8. 诗人层聚合公式

设诗人 a 的全量诗作集合为 P_a，全量句级单位集合为 U_a，候选句集合为 C_a = C ∩ U_a。

### 8.1 基础计数

```text
total_poem_count(a) = |P_a|
total_line_count(a) = |U_a|
matched_poem_count(a) = |{m ∈ P_a | C_m 非空}|
candidate_line_count(a) = |C_a|
candidate_line_rate(a) = candidate_line_count(a) / total_line_count(a)
```

### 8.2 句级高值计数

```text
line_p90_count(a) = |{u ∈ C_a | b(u) >= τ_l90}|
line_p95_count(a) = |{u ∈ C_a | b(u) >= τ_l95}|
line_ge08_count(a) = |{u ∈ C_a | b(u) >= 0.8}|
line_high_rate(a) = line_p90_count(a) / total_line_count(a)
line_high_within_candidate_rate(a) = line_p90_count(a) / candidate_line_count(a)
```

数量版统计中的 `line_high_count` 对应本报告中的 `line_p90_count`。数量榜按 line_high_count 从高到低排序。

### 8.3 诗级高值计数

```text
poem_p90_count(a) = |{m ∈ P_a | B(m) >= τ_p90}|
poem_p95_count(a) = |{m ∈ P_a | B(m) >= τ_p95}|
poem_ge08_count(a) = |{m ∈ P_a | B(m) >= 0.8}|
poem_high_rate(a) = poem_p90_count(a) / total_poem_count(a)
poem_high_within_matched_rate(a) = poem_p90_count(a) / matched_poem_count(a)
```

### 8.4 均值、中位数与最大值

对诗人 a 的候选句 best1 分数集合 S_{l,a} = {b(u) | u ∈ C_a}，计算：

```text
line_best_mean(a) = mean(S_{l,a})
line_best_median(a) = median(S_{l,a})
line_best_max(a) = max(S_{l,a})
```

诗级同理，对 S_{p,a} = {B(m)} 计算 `poem_best_mean`、`poem_best_median`、`poem_best_max`。

## 9. 密度统计公式

密度版统计将高值数除以诗人语料规模，主要用于比较不同诗人之间互文线索的相对集中度。

```text
候选句密度_每千句(a) = candidate_line_count(a) / total_line_count(a) × 1000
句级p90互文密度_每千句(a) = line_p90_count(a) / total_line_count(a) × 1000
句级p95互文密度_每千句(a) = line_p95_count(a) / total_line_count(a) × 1000
句级0.8互文密度_每千句(a) = line_ge08_count(a) / total_line_count(a) × 1000
诗级p90互文密度_每百首(a) = poem_p90_count(a) / total_poem_count(a) × 100
诗级p95互文密度_每百首(a) = poem_p95_count(a) / total_poem_count(a) × 100
诗级0.8互文密度_每百首(a) = poem_ge08_count(a) / total_poem_count(a) × 100
```

候选转化率用于说明召回后的候选中有多少进入高值区间：

```text
候选句转p90率(a) = line_p90_count(a) / candidate_line_count(a)
候选句转p95率(a) = line_p95_count(a) / candidate_line_count(a)
候选诗转p90率(a) = poem_p90_count(a) / matched_poem_count(a)
候选诗转p95率(a) = poem_p95_count(a) / matched_poem_count(a)
```

稳健样本门槛为 total_line_count >= 50 且 total_poem_count >= 10；大样本门槛为 total_line_count >= 500 且 total_poem_count >= 50。

全体诗人 2,492 位，稳健样本 343 位，大样本 127 位。

## 14. 统计解释边界

1. 本目录是候选召回后的精排统计，不是全量语义矩阵。候选召回依赖可见 3-gram，因此天然偏向显性词语重合、固定辞式、礼制公式和共同典源线索。
2. p90、p95 是候选集合内部阈值，不是外部学术判断标准。若候选集合改变，阈值也会改变。
3. best1 只保留每个候选句最相近的一条类书记录，便于统计，但会丢失第二、第三候选中的潜在线索。
4. 诗级结果由句级 best1 汇总，并非整诗全文重新编码。因此诗级分数应理解为该诗中最强候选句的分数。
5. 诗人密度指标会放大小样本偶然性；正式论述时应优先使用大样本榜，稳健榜前列的小体量诗人宜作为待复核线索。
6. 高相似度或高密度不等于直接影响关系，也不等于取材关系。需要结合共同典源、文本语境、诗人创作背景和人工校读继续判断。
7. 《全唐诗》来源 SQL 存在原始编码异常，数据准备阶段已作可逆乱码修复和诗人名尾随数字归一；作者归属仍以源数据为基础。
