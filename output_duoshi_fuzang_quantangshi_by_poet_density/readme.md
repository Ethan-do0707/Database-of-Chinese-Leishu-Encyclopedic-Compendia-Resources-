# 多识模型《白氏六帖》傅藏本 × 《全唐诗》诗人互文密度统计

本目录保存《全唐诗》诗人互文候选结果的密度版统计。密度版不重新编码向量，而是基于 `output_duoshi_fuzang_quantangshi_by_poet` 中的 `line_best1`、`poem_from_line_best1` 与诗人汇总结果，按诗人语料规模归一化。

上游互文统计使用的多识 embedding 模型为：`C:\duoshi_web\duoshi\models\fine_tuned\bge-large-zh-v1.5`。

## 核心口径

- 句级互文密度：句级 p90 高值数 / 诗人全量句级单位数 × 1000。
- 强互文密度：句级 p95 高值数 / 诗人全量句级单位数 × 1000。
- 诗级互文密度：诗级 p90 高值数 / 诗人全量诗作数 × 100。
- 稳健样本门槛：全量句级单位 >= 50 且诗作数 >= 10。
- 大样本门槛：全量句级单位 >= 500 且诗作数 >= 50。

## 注意事项

本结果仍建立在 `3-gram` 候选召回 + 多识精排之上，不是《全唐诗》全量语义矩阵。密度指标可用于比较不同诗人语料中互文线索的相对集中程度，但不宜直接解释为影响关系或取材关系。
