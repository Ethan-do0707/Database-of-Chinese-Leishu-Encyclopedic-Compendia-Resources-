# 《白氏六帖事類集》傅藏本结构化总结构说明

## 1. 文档用途

本文档用于说明傅藏本《白氏六帖事類集》结构化成果的来源、字段、统计概况、卷界依据、抽查情况与当前风险，便于后续校勘、引用、程序处理与对外说明。

本轮结构化的原则是：

- 结构化底本来自傅藏本 HTML 页面
- 当前 `JSON` 以人工复核后的总 Markdown 为准，并与之同步
- 《白孔六帖》只作为早期自动切分参照，不作为正文来源
- 卷界按傅藏本实际部类标题与北宋刻本三十卷框架综合判定

## 2. 主要输出文件

- `白氏六帖事類集_傅藏本_结构化.json`
- `白氏六帖事類集_傅藏本_结构化.md`
- `结构化诊断.json`
- `卷第一.md` 至 `卷第三十.md`
- `README.md`

其中：

- `JSON` 适合检索、统计、程序再处理
- `总 Markdown` 适合通读与全文人工校对
- `分卷 Markdown` 适合按卷逐步复核
- `结构化诊断.json` 记录 HTML 自动解析阶段各部类的切分模式与参考命中情况

## 4. 数据来源与处理方法

### 4.1 来源

本次结构化直接使用目录 `《白氏六帖》傅藏本/白氏六帖 傅藏本/` 中的 HTML 文件：

- `2038-0001.html`
- `2038-0002.html`
- `2038-0003.html`
- `2038-0004.html`

这些 HTML 页面保留了较清晰的部类标题与连续正文，优于此前纯 OCR 路径。

### 4.2 解析脚本

当前相关脚本为仓库根目录下的：

- `structure_baishi_liutie_fuzang.py`
- `sync_fuzang_json_from_markdown.py`

当前流程大致如下：

1. 读取傅藏本 HTML
2. 提取 `H2` 级部类标题与对应正文
3. 以“某门第一 / 一”作为新卷起点
4. 参照北宋刻本三十卷框架检查卷首门类
5. 用《白孔六帖》同卷同序号部类词表做词条前缀参照
6. 对未稳定命中的短句使用启发式切分
7. 对典型误切条目做定点后处理
8. 输出总 Markdown、分卷 Markdown、JSON 与诊断文件
9. 若总 Markdown 经人工校订，再用 `sync_fuzang_json_from_markdown.py` 反向同步更新 JSON

### 4.3 真实性说明

需要特别说明：

- 傅藏本结构化结果中的词条与注文，正文来源是傅藏本 HTML
- 当前 JSON 以人工复核后的总 Markdown 为直接同步来源
- 《白孔六帖》仅用于早期切分辅助与局部对照
- 不能把本文件理解为对白孔现成条文的直接复制

## 5. 字段结构

每条记录包含以下字段：

| 字段名 | 类型 | 说明 | 示例 |
| --- | --- | --- | --- |
| `卷` | `string` | 卷次，使用中文数字 | `一` |
| `部类` | `string` | 部类名称 | `天` |
| `部类序号` | `string` | 部类序号，使用中文数字 | `一` |
| `部类附名` | `string \| null` | 附门、附类等补充名目 | `地理土附` |
| `词条` | `string` | 结构化后的词条正文 | `高明柔克` |
| `注文` | `string \| null` | 与该词条对应的注文 | `高明，天也。柔克，寒暑不干。` |

## 9. 当前已知风险

尽管本版已达到可检索、可按卷复核的程度，但仍存在以下风险：

### 9.1 短句条目仍可能局部过细或过粗

尤其在以下类型中更明显：

- 并列短句
- 无引书标记的连写条目
- 词条极短、注文极短的密集段落

### 9.2 长引文条目前的短纲目有时失衡

部分记录可能出现：

- 词条偏短
- 注文偏长
- 引文续句被并得过多

### 9.3 附门内部的局部层次仍需人工判断

例如：

- `慶瑞附`
- `災食附`
- `地理附`
- `土附`

这些附门中的小条之间，仍可能需要更细的人工作业判断。

## 10. 使用建议

### 10.1 适合的用途

本结构化结果适合：

- 傅藏本《白氏六帖》逐卷校勘
- 词条级检索与统计
- 与《白孔六帖》或其他类书的互文对照
- 后续训练、标注与知识组织整理

### 10.2 建议的使用顺序

建议优先按如下顺序使用：

1. 先读 `傅藏本结构化总结.md`
2. 再看 `README.md` 与分卷文件
3. 需要程序处理时读取 `白氏六帖事類集_傅藏本_结构化.json`
4. 需要定位问题时参考 `结构化诊断.json`

### 10.3 后续校勘建议

若继续细修，建议优先处理：

1. 卷一天门中 `轉轂之狀`、`設位` 一带的连续短句
2. 诊断文件中参考命中偏低的部类
3. 并列短句与长引文交界处
